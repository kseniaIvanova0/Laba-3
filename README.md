## Описание
Программа рассчитывает число Фруда (Fr) и коэффициент газонасыщенности смеси (φ) для газожидкостной смеси, движущейся по трубе. 

Расчет выполняется для заданной серии скоростей (1, 2, 5, 10, 20, 50 м/с).
В зависимости от значения числа Фруда (меньше 50 или больше/равно 50) выбирается соответствующая формула для расчета коэффициента φ.

## Входные данные
- Диаметр трубы: 0.191 м
- Ускорение свободного падения: 9.81 м/с²
- Пороговое значение числа Фруда: 50.0
- Набор скоростей потока: 1.0, 2.0, 5.0, 10.0, 20.0, 50.0 м/с

## Выходные данные
Программа выводит таблицу с результатами расчетов, содержащую:
- Скорость потока (v) в м/с
- Число Фруда (Fr)
- Коэффициент газонасыщенности (φ)
